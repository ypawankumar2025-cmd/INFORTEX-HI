INFOTEX HI — PROJECT-AWARE AI UPGRADE
=====================================

This add-on keeps BOTH independent experiences:
  1. AI Chat: the existing general-purpose assistant, unchanged.
  2. Project AI: chats grounded in ONE selected project; project-specific history.

Project AI can discuss project description, task counts and selected tasks,
milestones, team member names/roles, recent comments, recent memories,
recent agent proposals, and short excerpts from recent uploaded documents.
Only a LIMITED snapshot is sent to your configured external AI provider.

Project AI is read-only. It DOES NOT create tasks or approve proposals itself.
"Send to Agent Team" explicitly starts the EXISTING multi-agent workflow,
which selects relevant agents; the human approval step remains mandatory
before approved tasks can be created. It does NOT necessarily invoke all 8
agents for each prompt.

HOW TO APPLY (RECOMMENDED: UPDATE ZIP)
--------------------------------------
1. Keep Docker Desktop running. Do not delete database volumes.
2. FIRST MAKE A BACKUP of your existing extracted HI folder (copy it).
3. Extract INFOTEX_HI_PROJECT_AI_UPDATE.zip to a separate directory.
4. Open the extracted directory, select its backend, database, frontend,
   and documentation files/folders, COPY, then paste into your existing HI
   folder. Allow Windows to MERGE folders and REPLACE same-name source files.
5. DO NOT overwrite or delete the local HI/.env file.
6. In your EXISTING HI folder's CMD, run:

   docker compose up -d --build

7. After Docker reports the frontend Started and backend/db Healthy,
   open http://localhost:8080 and press Ctrl+Shift+R.
8. In the sidebar, test "AI Chat" — old chats should remain.
9. Open "Project AI", choose a project, then ask:

   Explain my project's current progress, pending tasks, and biggest risks.

10. Ask a follow-up. Reload the page; reopen the conversation to check history.
11. If your workspace role permits writes, you can type a task-planning request
    and click "Send to Agent Team". Read the confirmation carefully. This
    creates a RUN/PROPOSAL in Intelligence Studio, not approved tasks.

BACKUP / SAFETY
---------------
- No .env, API keys, passwords, user chat data, or database volumes included.
- PostgreSQL data is in a Docker volume and is NOT part of a source-code ZIP.
- Keep your existing .env as-is. Rotate your OpenRouter key if it was exposed
  in an earlier shared ZIP, and update the local .env with the replacement.
- Avoid running "docker compose down -v" or "docker volume prune".
- Existing AI Chat uses 'chats' and existing chat tables, unmodified.
- New Project AI uses 'project-chats' and two new database tables.
- You can restore original source files from your backup if necessary.

LIMITATIONS
-----------
- AI messages are generated by the external free model and can be incorrect.
- General AI Chat has no automatic access to project data.
- Project AI does not do live web browsing or execute agent actions via chat.
- Only recent project records are summarized; this is NOT a complete export.
- Selecting a new project intentionally switches to a different chat list.
